# 🌤️ Weather Forecast App

A beautiful and simple **React Weather Forecast App** that shows the current weather, upcoming 4-day forecast, UV index, humidity, wind, sunrise/sunset, and more — all with dynamic weather icons and images.

![Screenshot](./assets/weather-app.png)

## 🚀 Live Demo

👉 [Click to View Live](https://your-live-demo-link.netlify.app)

---

## ✨ Features

- 🔍 Search any city to get the latest weather
- 📆 4-Day forecast with max/min temperature
- 🌇 Sunrise and sunset times
- 🌡️ Feels-like temperature and humidity
- 🌬️ Wind speed and UV index
- 🎨 Dynamic weather icons & background images
- 📱 Responsive layout for all screen sizes

---

## 🛠️ Technologies Used

- React.js (Functional Components + Hooks)
- WeatherAPI.com (free weather API)
- CSS3 (custom styling with responsive design)
- Free weather icons and images
